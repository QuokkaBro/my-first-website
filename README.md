# my-first-website

HTML, CSS, JavaScript만 사용해서 만든 간단한 자기소개 웹사이트입니다.

## 실행 방법

1. 이 저장소의 `index.html` 파일을 찾습니다.
2. `index.html`을 브라우저에서 열면 웹사이트를 바로 볼 수 있습니다.

## 파일 설명

- `index.html`: 웹사이트의 글, 버튼, 섹션 같은 기본 내용을 담고 있습니다.
- `style.css`: 색상, 글자 크기, 카드, 버튼 등 전체 디자인을 담당합니다.
- `script.js`: 연락처 버튼 메시지와 다크 모드 버튼 동작을 담당합니다.

## 쉽게 바꿀 수 있는 부분

- 이름과 소개글은 `index.html`에서 바꿀 수 있습니다.
- 대표 색상과 배경색은 `style.css` 위쪽의 `:root` 영역에서 바꿀 수 있습니다.
- 연락처 버튼 메시지는 `script.js` 위쪽의 `contactMessage` 문장에서 바꿀 수 있습니다.
